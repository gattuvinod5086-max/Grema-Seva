1. ❌ Dev server is NOT running → App won't load

================================================================================
STEP 1: START THE SERVER
================================================================================

Open a terminal and run:

    cd /Users/vinod.gattu/Downloads/GramSeva
    npm run dev

You should see:
    VITE v7.x.x  ready in xxx ms
    ➜  Local:   http://localhost:5173/

Then open: http://localhost:5173

================================================================================
STEP 2: FIX AUTHENTICATION (Get API Key)
================================================================================

1. Go to: https://getmocha.com/dashboard
2. Sign in (or create account)
3. Find "API Keys" in Settings
4. Copy your API key

================================================================================
STEP 3: ADD API KEY TO PROJECT
================================================================================

Run this command:

    nano .dev.vars

Find this line:
    MOCHA_USERS_SERVICE_API_KEY=your_api_key_here

Replace with your actual key:
    MOCHA_USERS_SERVICE_API_KEY=mo_your_actual_key_here

Save: Press Ctrl+X, then Y, then Enter

================================================================================
STEP 4: RESTART SERVER
================================================================================

After adding the API key, restart the server:

    # Stop server (Ctrl+C)
    npm run dev

================================================================================
VERIFY IT WORKS
================================================================================

1. Open: http://localhost:5173
2. Click: "Sign in with Google"
3. Should redirect to Google OAuth ✅

Or run: ./start-and-check.sh
